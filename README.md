## Hi, I'm Muhammad Haseeb Ul Hassan 👋

BSCS student at Forman Christian College University, minoring in Data Analytics & Mathematics. I build full-stack tools aimed at real problems, not just coursework.

- 📊 **Focus areas:** Data Structures & Algorithms, Statistical Modeling, Full-Stack Development
- 🛠️ **Tech Stack:** Python | TypeScript | R | C/C++ | FastAPI | React Native | Next.js | PostgreSQL
- 🚀 **Currently building:** Sukoon, an elder-care coordination app for the Pakistani diaspora, and FCCU Info Hub, a campus events platform — plus prepping for URAAN's AI Techathon
- 🎯 **Currently learning:** applied AI in production systems, database design at scale
